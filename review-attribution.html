Review Insights

Turn a location's Google reviews into per-staff sentiment signals — separating the overall visit rating from how each named person was actually spoken about. A supporting signal for reviews, not an automated scorecard.

2 · Review files

One CSV per location. The file name is the office name (e.g. Westport.csv). Columns: Reviewer, Rating, Date, MonthsAgo, ApproxDate, Review.

Drop one or more review CSVs here or browse

Match each review file to an office

The file name is the only link between a review file and a roster office, so confirm every match before anything is scored. Unmatched files are skipped; roster offices with no file get no data.

Attribute reviews to staff

Names are matched deterministically against the roster (word-boundary, alias-aware). Every matched person then gets their own sentiment and a confidence score — a review can praise one person and fault another in the same breath.

How sentiment is scored. The rules engine runs instantly and offline: it scores the clause around each matched name and flags every result for your review. Switching to Claude — live (a later add) reads each mention for the sentiment directed at that specific person, handling contrast, pronouns, sarcasm, and self-introductions. Either way the overall star rating stays separate — it describes the whole visit, not the person.

Sentiment keyword lists

The rules engine scores a person's clause against these word/phrase lists (one per line, case-insensitive). Uploading a file replaces that list for this session — download the current one first to use as your starting point. These also travel inside the combined settings JSON (Upload step) as sentimentKeywords.positive / .negative, so you don't have to manage them separately.

Locations:

Date, star, and category filters narrow which reviews are in scope everywhere below, including each person's profile. Sentiment and staff member narrow which mentions count toward mention-based stats (staff mentions, location average, per-person cards), since both belong to a specific person's mention, not a whole review. Check multiple Locations above to see someone who works at more than one office combined into a single card and profile — matched by their exact name across offices, so keep spelling consistent in the roster.

This tool surfaces one signal among many. Mention-based scores are self-selected (delighted and upset customers name names; most don't), volume varies by shift, and small samples are noisy — so treat these as conversation starters in a fair review process, not as a standalone basis for pay or discipline.
